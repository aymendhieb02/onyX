# Tetris Pro - Futuristic Web Version

A modern, futuristic Tetris game built with Next.js, React, and TypeScript. Designed for adults with a sleek, professional interface and advanced features.

## 🚀 Features

### Core Gameplay
- **Classic Tetris Mechanics**: Full implementation of standard Tetris rules
- **Multiple Game Modes**: Classic, Sprint, Ultra, and Custom challenges
- **Ghost Piece Preview**: See where your piece will land
- **Hold Feature**: Save a piece for later use
- **Smooth Animations**: 60fps gameplay with fluid animations

### Modern UI/UX
- **Futuristic Design**: Neon effects, glowing borders, animated backgrounds
- **Ghost Cursor**: Custom cursor effect inspired by modern web design
- **Responsive Layout**: Works on desktop, tablet, and mobile
- **Dark Theme**: Easy on the eyes with customizable colors

### Interactive Features
- **Chat Assistant**: AI-powered helper for game questions
- **Real-time Stats**: Live score, level, lines, and time tracking
- **Keyboard Controls**: Full keyboard support with customizable bindings
- **Visual Feedback**: Particle effects, line clear animations, level transitions

## 🎮 Game Modes

### Classic
Endless gameplay with progressive difficulty. Level up every 10 lines cleared.

### Sprint
Clear 40 lines as fast as possible. Perfect for speedrunners!

### Ultra
Score as many points as possible in 2 minutes. Strategy meets speed.

### Custom
Create your own challenges with custom rules and parameters.

## ⌨️ Controls

- **Arrow Left/Right**: Move piece horizontally
- **Arrow Down**: Soft drop (faster fall)
- **Arrow Up / X**: Rotate clockwise
- **Z**: Rotate counter-clockwise
- **Space**: Hard drop (instant drop)
- **C**: Hold piece
- **ESC**: Pause/Resume

## 🛠️ Tech Stack

- **Next.js 14**: React framework with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first styling
- **Framer Motion**: Smooth animations
- **Zustand**: State management (if needed)

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the game.
