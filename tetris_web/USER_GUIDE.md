# Tetris Pro - User Guide

Welcome to Tetris Pro! This guide will help you master the game.

## Getting Started

### Launching the Game

1. Open the game in your web browser
2. You'll see the main menu with four game modes
3. Click on a mode to start playing
4. Use keyboard controls to play (see Controls section)

## Game Modes Explained

### 🎮 Classic Mode
- **Objective**: Play as long as you can
- **Difficulty**: Increases every 10 lines cleared
- **Best For**: Casual play, practice, high scores
- **Strategy**: Focus on clearing multiple lines at once (Tetris!)

### ⚡ Sprint Mode
- **Objective**: Clear 40 lines as fast as possible
- **Time Limit**: None (but time is tracked)
- **Best For**: Speedrunners, competitive players
- **Strategy**: Speed and efficiency are key. Use hard drops!

### 🏆 Ultra Mode
- **Objective**: Score maximum points in 2 minutes
- **Time Limit**: 2 minutes
- **Best For**: High score chasers
- **Strategy**: Balance speed with multi-line clears for maximum points

### 🎯 Custom Mode
- **Objective**: Set your own challenge
- **Options**: Customize line goals, time limits, starting level
- **Best For**: Practice specific skills, custom challenges

## Controls Reference

### Movement
- **← (Left Arrow)**: Move piece left
- **→ (Right Arrow)**: Move piece right
- **↓ (Down Arrow)**: Soft drop (faster fall, no bonus points)

### Rotation
- **↑ (Up Arrow) or X**: Rotate clockwise
- **Z**: Rotate counter-clockwise

### Advanced
- **Space**: Hard drop (instant drop, bonus points)
- **C**: Hold piece (swap with held piece)
- **ESC**: Pause/Resume game

## Scoring System

### Line Clears
- **1 Line (Single)**: 100 × current level
- **2 Lines (Double)**: 300 × current level
- **3 Lines (Triple)**: 500 × current level
- **4 Lines (Tetris)**: 800 × current level ⭐

### Bonuses
- **Hard Drop**: 2 points per cell dropped
- **Level Multiplier**: Higher levels = more points per line

### Pro Tips
- Aim for Tetris (4 lines) for maximum points
- Use hard drops strategically for bonus points
- Higher levels = exponentially more points

## Game Mechanics

### Ghost Piece
The ghost piece shows where your current piece will land. Use it to plan your placement!

### Hold Feature
- Press **C** to hold the current piece
- You can swap between current and held piece
- Can only hold once per piece placement
- **Strategy**: Hold pieces that don't fit well, use them later

### Level Progression
- Level increases every **10 lines cleared**
- Each level = faster falling speed
- Higher levels = more points per line
- Speed formula: `1000ms - (level - 1) × 50ms`

### Game Over
The game ends when:
- A new piece cannot spawn (blocks reach the top)
- This is called "topping out"

## Strategies & Tips

### Beginner
1. **Focus on clearing lines**: Don't worry about Tetris yet
2. **Keep it flat**: Avoid building too high on one side
3. **Use the ghost**: Plan where pieces will land
4. **Practice rotation**: Learn how each piece rotates

### Intermediate
1. **Aim for Tetris**: Save the I-piece for 4-line clears
2. **Use hold strategically**: Save difficult pieces
3. **Build on one side**: Create a well for Tetris
4. **Soft drop for positioning**: Use down arrow to fine-tune placement

### Advanced
1. **T-Spin setups**: Learn T-spin techniques for extra points
2. **Stacking patterns**: Use specific stacking patterns
3. **Speed techniques**: Master hard drops and quick rotations
4. **Multi-line planning**: Plan 2-3 moves ahead

## Understanding the HUD

### Stats Display
- **Score**: Your current total points
- **Level**: Current difficulty level
- **Lines**: Total lines cleared
- **Time**: Time played (in Sprint/Ultra modes)

### Next Piece
Shows the upcoming piece so you can plan ahead.

### Hold Piece
Shows your held piece. Empty if nothing is held.

## Performance Tips

1. **Use a modern browser**: Chrome, Firefox, or Edge for best performance
2. **Close other tabs**: For smoother gameplay
3. **Disable extensions**: Some extensions can affect performance
4. **Fullscreen mode**: Press F11 for immersive experience

## Troubleshooting

### Game is laggy
- Close other browser tabs
- Disable browser extensions
- Try a different browser
- Check your computer's performance

### Controls not working
- Make sure the game window is focused
- Check if another application is capturing keyboard input
- Try refreshing the page

### Can't see ghost piece
- Ghost piece appears as a semi-transparent version
- Make sure you're looking at the game board
- Ghost shows where the piece will land
